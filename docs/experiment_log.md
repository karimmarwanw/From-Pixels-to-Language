| 2026-11-01 | Karim | Grad-CAM, first attempt (**failed**: blank heatmaps) | Grad-CAM as in the paper (Selvaraju et al., ICCV 2017): gradients of the raw logit of the predicted class at `encoder.gradcam_layer` | 30% of the ResNet50 maps completely blank, the rest a single small dot | The final ResNet50 gives every class a negative logit: the predicted logit is < 0 for 98% of val images, and the winner is just the least negative. Softmax ignores a shift shared by all classes, but the raw-logit map does not: that shared negative part dominates every cell, and the ReLU erases it. Fix: explain `y_c − mean_j(y_j)` (predicted class vs the average class), which removes only the shared part → 0% blank maps. The paper's version stays available (`relative=False`); a test checks both against the formula computed by hand. The scratch CNN did not have the problem (10% negative predicted logits). |
