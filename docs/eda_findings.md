# EDA findings → decisions (Task 1.1)

CUB-200-2011 with captions (`Multimodal-Fatima/CUB_train`, `Multimodal-Fatima/CUB_test`).
Every number below comes from `outputs/eda/stepNN_output.txt` (regenerated by the commands at the end).

> **Test set.** The test set was not used during the EDA. All analysis and fitted statistics
> come from the official training set. The test set is checked once, at final evaluation:
> integrity (does every image load, how many are non-RGB) and train-vs-test duplicates (leakage).

## 1. Dataset overview

| | Value |
|---|---|
| Official train / test images | 5,994 / 5,794 |
| Classes (species) | 200, names read from the dataset (`ClassLabel`) |
| Captions | 10 per image, stored in one `description` string separated by `\n` |
| Our split of the official train set | **5,095 train / 899 val** (stratified 85/15, seed 42) → `data/splits/split.json` |

## 2. Findings → decisions

| Step | Finding | Evidence | Decision |
|---|---|---|---|
| 1 | `description` is one string with 10 captions and a **trailing `\n`** | 5,994 of 5,994 descriptions; naive split gives 11 pieces | Split on `\n`, strip, drop empty pieces |
| 1 | Images keep their stored mode (`Image(mode=None)`) | schema | `.convert("RGB")` explicitly on load |
| 2 | Train set is **balanced** | 29–30 images/class; 194 classes have 30, 6 have 29; max/min = **1.034** | No class weights or resampling |
| 2 | Few images per class | ~30 per class (≈25 after the split) | Transfer learning + augmentation; expect a weak scratch baseline |
| 2 | Balanced classes, but 200 of them | — | Report accuracy **and** macro precision/recall/F1 (every species counts equally) |
| 3 | **No corrupted files** | 5,994 / 5,994 decode fully; all JPEG | Nothing to remove |
| 3 | **5 grayscale images**, 1 of them stored as RGB | 4 in mode `L` + California Gull (row 1743, channel diff ≤ 3) | Keep for classification (converted to RGB); **exclude from M2 colorization** |
| 3 | Images are ~500×375 | median 500×375; longest side = 500 for 92.3%; short side median 357 | Input size **224** (almost every image is downscaled) |
| 3 | Few small images | **74** (1.2%) have short side < 224 px | Keep; they are upscaled (blurrier) |
| 3 | Extreme aspect ratios | **15** very wide (> 2.0, max 3.60), **1** very tall (< 0.5) | Keep; center crop may cut part of the bird (limitation) |
| 3 | Lighting varies a lot | **14** very dark (mean < 35), **29** very bright (mean > 220) | Mild brightness/contrast augmentation |
| 3 | 133 images (2.2%) are unusual in at least one way | summary table, step 3 | Too few to need special handling |
| 4 | **3 duplicate pairs**, all same species | 1 exact (MD5), 1 resized (500×333 vs 200×133), 1 edited (brightness/contrast); pHash distance ≤ 4 | Keep all; **put each pair on the same side of the split** |
| 4 | pHash threshold must be low | every inspected pair at distance ≥ 6 was a different photo (plain sky/water backgrounds); median nearest distance = 16 | Duplicate = distance ≤ **4** bits |
| 5 | Task is **fine-grained** | 167 of 200 species share a family name (25 warblers, 21 sparrows, 8 gulls, 7 terns) | Transfer learning; check most-confused pairs in Task 1.2 |
| 5 | **Color** separates look-alike species | gull bills, warbler throats; 97.6% of captions mention a color (step 6) | **No hue/saturation jitter, no grayscale** augmentation |
| 5 | Birds face left or right, photographed upright | sample grids | Horizontal flip yes, **vertical flip no** |
| 5 | Some images contain text, even the species name | watermark "Bohemian Waxwing" (row 5543), photographer credits | Keep; check with Grad-CAM that the model looks at the bird |
| 6 | **27 captions with broken spaces** (U+FFFD) | every space became `��`; words intact | **Repair**: replace U+FFFD runs with a space |
| 6 | **583 images repeat a caption** | 639 extra copies (1 image has the same sentence 4×) | **Drop repeats within an image** |
| 6 | Template captions reused across images, sometimes wrong | "this bird has wings that are brown and has a white belly" ×601; only 84.2% of captions are unique | **Keep**; report as caption noise / M2 risk |
| 6 | One cut-off caption | `'this'` (1 word) | Drop captions with < 2 words |
| 6 | Typos are rare and mostly bird terms | 0.84% of tokens unknown to a dictionary; e.g. *retrices* ×332, *supercillary* ×68; spellchecker suggestions often wrong (*eyering* → "eyeing") | **No automatic spellcheck**; 41-entry hand-checked map (`configs/caption_typos.yaml`) |
| 6 | Punctuation is inconsistent | 52,467 commas, 47,305 periods, missing spaces (`feathers,brown`) | **Remove punctuation**; keep apostrophes in words, `&` → "and" |
| 6 | Numbers are rare but meaningful | 65 captions ("2 white wing bars", "2.5 times") | **Keep numbers** |
| 6 | Caption length | median 14 words; 95th pct 24; 99th pct **32**; max 66 | M2: max caption length ≈ 32 tokens |
| 6 | Vocabulary is long-tailed | 4,067 words; 60% seen ≤ 2 times; min freq ≥ 5 keeps 1,240 words covering 99.5% of tokens | M2: min word frequency ≈ 3–5, built on the train part only |
| 7 | Stratified 85/15 split works | 5,095 / 899; 25–26 train and 4–5 val per class; all 6 checks pass | Val for tuning, early stopping, model selection; test untouched |
| 7 | Val is small per class | 4–5 images per class | Select models by **overall** val metrics, not per-class |
| 8 | CUB colors are close to ImageNet | mean diff R −0.001, G **+0.042**, B **+0.026**; std diff ≤ 0.035 (greener/bluer backgrounds) | **ImageNet mean/std for both models** (fair scratch vs transfer comparison) |
| 9 | Cleaning applied | 59,940 → **59,289** captions; 0 images lost; every image keeps 7–10 captions; 0 U+FFFD and 0 punctuation left | `data/processed/captions.json` for M2 |
| 10 | Train augmentation | RandomResizedCrop(scale 0.5–1.0), H-flip 0.5, rotation ±15°, brightness/contrast ±0.2 | `build_train_transform` in `src/data/transforms.py` |
| 10 | Val/test preprocessing | Resize short side 256 → CenterCrop 224 | `build_eval_transform` (deterministic) |
| 10 | Normalized batches are centred | 256 random train images: mean (−0.02, +0.14, +0.02), std (1.00, 0.98, 1.13) | Normalization works as predicted in step 8 |

## 4. Known limitations

- **Template captions** (e.g. ×601) are sometimes inaccurate for the bird (a Gray Catbird with gray wings described as "brown wings"); kept, so M2 models may learn generic sentences.
- **Watermarks / text** in some images, one with the species name ("Bohemian Waxwing"); not removable reliably.
- **Center crop on extreme shapes** (16 images) can cut off part of the bird (e.g. the raven's head, row 3228).
- **Random crops in training** sometimes cut part of a small bird (seen in the step 10 figure).
- **Rare typos** (< 5 occurrences, e.g. *reacing*) are left as they are; they become `<unk>` in the M2 vocabulary.
- **Train-vs-test duplicates** are not checked during the EDA (test untouched); the check runs once at final evaluation with `find_near_duplicates(train, max_distance, test)`.

## 6. How to reproduce

```bash
pip install -r requirements.txt
python -m src.cli eda --config configs/eda.yaml --step 1    # ... up to --step 10
pytest -q                                                   # caption cleaning + transform tests
```

Each step prints its report and saves it to `outputs/eda/stepNN_output.txt`.
The first run downloads the dataset (~1.1 GB) into `data/hf_cache/`.
